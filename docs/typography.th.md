# ตัวอักษรมีผู้อ่าน

การอ่านของ Dr Non ต่อ Robert Bringhurst, *The Elements of Typographic Style* ใช้พิมพ์ครั้งที่สอง ปี 1997 อ่านเลือก ไม่ได้อ่านจบ

กฎข้อ III ผูกขนาดกับระยะบรรทัด สามขนาดนั้นเป็นระบบที่เราเลือก ไม่ใช่กฎสากลจาก Bringhurst และไม่ใช่ตัวอักษรของ MoMA เก็บกฎที่รันได้นั้นไว้ ก่อนประกาศว่างานจบ ให้เพิ่มการพิสูจน์ต่อผู้อ่านในหน้านี้

## ขั้นตอน

1. อ่านข้อความจริง บอกว่าผู้อ่านกำลังทำอะไร สื่อคืออะไร อักษรคืออะไร และนโยบายฟอนต์ที่มีอยู่ในโครงการคืออะไร วางบทบาทของหัวเรื่อง ย่อหน้า การกระทำ คำบรรยาย และข้อผิดพลาด
2. พิสูจน์ครอบครัวตัวบทที่อนุมัติไว้ก่อน หน้าชื่อจะกลายเป็นตัวบทเพียงเพราะมันดูหนักไม่ได้ ถ้าครอบครัวเดียวครอบคลุมบทบาทจริง ให้เหลือครอบครัวเดียว
3. เทียบตัวคู่ด้วยสัดส่วน ความต่างของเส้น ขนาดที่ตาเห็น และจังหวะ ไม่ใช่แค่ป้ายเซริฟหรือซานเซริฟ ตัวคู่ต้องมีบทบาท และสัญญาต้องอนุญาต
4. จับขนาด ระยะบรรทัด ความยาวบรรทัด และระยะไว้ด้วยกัน ใช้บรรทัดจริง อย่าใช้กฎว่า 66ch พอดีกับร้อยแก้วทุกแบบและทุกอักษร หน่วย `ch` ใน CSS คือความกว้างของอักขระศูนย์
5. แยกตัวพิมพ์ใหญ่เล็กและการถ่างของละติน ออกจากกฎของไทยและจีน ตรวจเครื่องหมายซ้อน วรรคตอน การตัดบรรทัด และการครอบคลุมอักษร ที่สัญญาของบ้านรับไม่ไหว ให้ขอข้อยกเว้นที่ระบุขอบเขต แล้วให้คนที่อ่านคล่องดู
6. พิสูจน์ที่ความกว้างโทรศัพท์ ข้อความที่ขยาย ฟอนต์ที่ถูกบล็อก สีจริง และน้ำหนักที่มีอยู่ จดสิ่งที่พัง ไม่ใช่แค่สิ่งที่เครื่องมือตรวจผ่าน

## ใบรับ

ผู้อ่าน งาน สื่อ เนื้อจริง ครอบครัวที่อนุมัติตามบทบาท น้ำหนักและสัญญาอนุญาตที่ใช้จริง ฟอนต์สำรอง ทางเลือกที่ปฏิเสธพร้อมเหตุที่เห็น ขนาด ระยะบรรทัด ความยาวบรรทัด เงื่อนไขการพิสูจน์และความล้มเหลว ข้อยกเว้น งานที่ยังรอคนอ่านคล่องหรือคนตรวจ

คำอธิบายที่จำเป็นแต่อ่านไม่ได้ กั้นการปล่อย แสดงตัวอย่างที่พัง แล้วขอข้อยกเว้นที่เขียนไว้ในโครงการ อย่าเพิ่มขนาดที่สี่อย่างเงียบ ๆ และอย่าอ้างว่ากฎข้อ III การันตีว่าใช้ได้ `type-scale` ที่มีอยู่ตรวจวินัยของโทเคน ไม่ได้ตรวจว่าจัดตัวอักษรแล้วอ่านได้ และไม่ได้ตรวจว่าคนเป็นคนเขียน

มันจับคู่เฉพาะ `font-size: Npx` เปล่า ๆ มันไม่อ่าน `line-height` และไม่เห็น `clamp()` `lint/laws-check.mjs` จับระยะบรรทัดใน `micro 11/16` ได้ แล้วไม่เอาไปเทียบกับ `LEADING` ใน `lint/scale.mjs`

## สิ่งที่หน้าสาธิตตั้งไว้

เรนเดอร์เมื่อ 2026-10-12 วิวพอร์ต 1280×900 ตัวบทเป็น IBM Plex Sans ที่ 14px / 20px ซึ่งเป็นโทเคนตัวบท ชื่อเรื่องเป็น `clamp(32px, 7vw, 64px)` กับ `line-height: 1.02` คำนวณได้ 64px / 65.28px น้ำหนัก 700 นั่นคือขนาดที่สี่ วันเดียวกัน `node lint/moma-lint.mjs examples --strict` รายงาน 0 รายการ กฎข้อ III ไม่ล้ม เพราะตัวตรวจไม่เห็นประกาศนี้

ป้ายจิ๋วบนหน้านั้นเป็นตัวพิมพ์ใหญ่ และถ่างระยะ เสียงของสถาบันที่ MoMA ไม่ทำแบบนี้ ดู [moma-vs-us.md](moma-vs-us.md) ซึ่งยังเป็นบันทึกการวัดภาษาอังกฤษ ไทยและจีนไม่รับการถ่างระยะและการเปลี่ยนตัวพิมพ์ของละตินมาใช้ คำแปลที่ถ่างอักษรไทย หรือทำจีนเป็นตัวพิมพ์ใหญ่ทั้งก้อน พังต่อผู้อ่านที่บันทึกนี้มีไว้ดูแลแล้ว
